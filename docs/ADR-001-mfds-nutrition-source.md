# ADR-001: 영양 데이터는 식약처 DB만 사용

- 상태: 확정
- 결정일: 2026-09-13
- 대상: 앱에 표시·계산·저장되는 음식 영양값

BodyFlow의 음식 영양값은 공공데이터포털 `식품의약품안전처_식품영양성분DB정보`만 사용한다. 폐기된 과거 API, 민간 레시피 수치, 사용자 입력값은 영양 데이터 출처로 사용하지 않는다.

API 응답은 `FoodItem`의 11개 필드로만 변환한다. `source`는 항상 `mfds`이고 `source_id`는 식약처 식품코드다. 로컬 SQLite 캐시는 이 변환을 통과한 항목만 저장하며 `source_id`를 기본 키로 삼아 같은 음식의 충돌하는 복제본을 허용하지 않는다.

사용자는 공식 항목의 양을 조합할 수 있지만 kcal·탄수화물·단백질·지방·나트륨 값을 등록하거나 수정할 수 없다. 조합 값은 기준 제공량 대비 선택한 중량의 비율로 계산한다. 검색 결과가 없으면 영양값을 만들지 않고 유사한 공식 캐시 항목 세 개만 제안한다.

운영 키는 저장소 밖 `.env`의 `MFDS_SERVICE_KEY`로만 주입한다. `.env`는 Git에서 제외한다.
